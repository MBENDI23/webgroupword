# James Okello 2026 - Campaign Website

A professional multi-page campaign website for James Okello's 2026 presidential campaign in Uganda. Built with HTML, CSS, and JavaScript for easy deployment on any web hosting platform.

## Project Overview

This static website features:
- **6 Complete Pages**: Home, About, Vision, Activities, Contact, and Gallery
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Uganda Theme**: Custom color scheme based on Uganda flag colors (yellow, red, black)
- **Interactive Features**: Contact forms, volunteer registration, photo gallery filters
- **Professional Design**: Clean, modern layout suitable for a political campaign

## Website Structure

```
static-website/
├── index.html          # Home page with hero section and candidate introduction
├── about.html          # Biography, timeline, and background information

└── README.md          # This documentation file
```

## Free Web Hosting Options

For academic projects, here are excellent free hosting platforms:

### 1. **GitHub Pages** (Recommended)
- **Cost**: Completely free
- **Features**: Custom domains, HTTPS, unlimited bandwidth
- **Setup**: Upload files to GitHub repository, enable Pages in settings
- **URL Format**: `username.github.io/repository-name`
- **Pros**: Professional, reliable, version control included
- **Best for**: Academic projects and professional portfolios

### 2. **Netlify**
- **Cost**: Free tier with generous limits
- **Features**: Drag-and-drop deployment, custom domains, form handling
- **Setup**: Drag website folder to Netlify dashboard
- **URL Format**: `sitename.netlify.app` or custom domain
- **Pros**: Extremely easy deployment, built-in form processing
- **Best for**: Quick deployment and form functionality

### 3. **Vercel**
- **Cost**: Free tier for personal projects
- **Features**: Global CDN, custom domains, automatic deployments
- **Setup**: Connect GitHub repository or upload files
- **URL Format**: `sitename.vercel.app` or custom domain
- **Pros**: Fast performance, automatic HTTPS
- **Best for**: Modern web applications

### 4. **Firebase Hosting**
- **Cost**: Free tier (1GB storage, 10GB bandwidth/month)
- **Features**: Global CDN, custom domains, SSL certificates
- **Setup**: Install Firebase CLI and deploy with commands
- **URL Format**: `projectname.web.app` or custom domain
- **Pros**: Google infrastructure, excellent performance
- **Best for**: Projects requiring backend integration

### 5. **Surge.sh**
- **Cost**: Free for static sites
- **Features**: Custom domains, instant deployment
- **Setup**: Install Surge CLI and run `surge` command
- **URL Format**: `subdomain.surge.sh` or custom domain
- **Pros**: Simple command-line deployment
- **Best for**: Developers comfortable with command line

## Deployment Instructions

### Option 1: GitHub Pages (Recommended)
1. Create a GitHub account at github.com
2. Create a new repository named `james-okello-2026`
3. Upload all website files to the repository
4. Go to repository Settings > Pages
5. Select "Deploy from a branch" and choose "main"
6. Your site will be available at `yourusername.github.io/james-okello-2026`

### Option 2: Netlify (Easiest)
1. Visit netlify.com and create account
2. Drag and drop the `static-website` folder onto Netlify dashboard
3. Your site is instantly live with a generated URL
4. Optional: Add custom domain in site settings

### Option 3: Vercel
1. Visit vercel.com and sign up
2. Click "New Project" and upload your files
3. Site deploys automatically
4. Access via generated `.vercel.app` URL
